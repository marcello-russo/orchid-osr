# 🌸 OrchID — Frontend Explorer

React Single Page Application (SPA) for exploring and analyzing the results of *Ophrys* orchid classification models.

## 🚀 Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Shadcn/ui
- **State & Data**: Zustand, React Query, Recharts

## 🛠️ Quick Start

```bash
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`. It requires the OrchID backend running on port `5000` (API calls are proxied automatically via `vite.config.ts`).
